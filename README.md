# 🚦 Traffic Accident Analysis

## 📖 Project Overview

This project analyzes the US Accidents dataset to identify patterns related to road conditions, weather conditions, and time of day. The goal is to discover accident hotspots and understand the major factors contributing to traffic accidents.

---

## 🎯 Objectives

- Analyze traffic accident patterns
- Study the impact of weather conditions on accidents
- Examine accident occurrence by time of day
- Identify accident hotspots using geographical data
- Visualize key contributing factors through charts and maps

---

## 📊 Dataset Information

**Dataset:** US Accidents (2016–2023)

## Dataset

The dataset used in this project is too large to be included in this repository.

You can download it from:
https://www.kaggle.com/datasets/sobhanmoosavi/us-accidents

The dataset contains millions of traffic accident records collected from various sources across the United States. It includes information about accident severity, weather conditions, location, visibility, temperature, and time.

## 🔍 Key Insights

- Most accidents occur during peak traffic hours.
- Weather conditions significantly influence accident frequency.
- Low visibility conditions often contribute to severe accidents.
- Certain regions show higher accident concentrations.
- Time of day plays a major role in accident occurrence.
